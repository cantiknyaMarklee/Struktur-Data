Materi Lengkap Struktur Data

Stack

Stack adalah struktur data linear yang menggunakan konsep LIFO (Last In First Out). Data yang terakhir masuk akan menjadi data pertama yang keluar.

Stack sering digunakan pada browser history, undo-redo, dan call stack function.

Contoh Program Stack
stack = []

stack.append("Andi")
stack.append("Budi")
stack.append("Citra")

print(stack)

stack.pop()

print(stack)

Queue

Queue menggunakan konsep FIFO (First In First Out). Data pertama yang masuk akan menjadi data pertama yang keluar.

Queue digunakan pada sistem antrian printer, tiket, dan request server.

Contoh Program Queue
from collections import deque

queue = deque()

queue.append("A")
queue.append("B")
queue.append("C")

print(queue)

queue.popleft()

print(queue)

Deque

Deque adalah Double Ended Queue yang memungkinkan penambahan dan penghapusan data dari dua sisi.

Contoh Program Deque
from collections import deque

D = deque()

D.append(10)
D.appendleft(5)

print(D)

D.pop()

print(D)

Bubble Sort

Bubble Sort adalah algoritma pengurutan sederhana dengan cara membandingkan dua data berdekatan lalu menukarnya jika urutan salah.

Contoh Program Bubble Sort
data = [5, 2, 8, 1]

for i in range(len(data)):

    for j in range(len(data)-1-i):

        if data[j] > data[j+1]:
            data[j], data[j+1] = data[j+1], data[j]

print(data)

Selection Sort

Selection Sort bekerja dengan memilih nilai terkecil lalu menempatkannya pada posisi yang benar.

Contoh Program Selection Sort
data = [64, 25, 12, 22, 11]

for i in range(len(data)):

    min_index = i

    for j in range(i+1, len(data)):

        if data[j] < data[min_index]:
            min_index = j

    data[i], data[min_index] = data[min_index], data[i]

print(data)

Insertion Sort

Insertion Sort menyisipkan data ke posisi yang tepat pada bagian data yang sudah terurut.

Contoh Program Insertion Sort
data = [12, 11, 13, 5, 6]

for i in range(1, len(data)):

    key = data[i]
    j = i - 1

    while j >= 0 and key < data[j]:
        data[j + 1] = data[j]
        j -= 1

    data[j + 1] = key

print(data)

Recursion

Rekursif adalah teknik pemrograman dimana fungsi memanggil dirinya sendiri.

Contoh Program Rekursif
def faktorial(n):

    if n == 1:
        return 1

    return n * faktorial(n-1)

print(faktorial(5))

Sequential Search

Sequential Search adalah metode pencarian data satu per satu dari awal hingga akhir.

Contoh Program Sequential Search
data = [4, 7, 1, 9, 3]

key = 9

for i in range(len(data)):

    if data[i] == key:
        print("Data ditemukan")
        break

Binary Search

Binary Search adalah teknik pencarian cepat pada data yang sudah terurut.

Contoh Program Binary Search
data = [1, 3, 5, 7, 9, 11]

key = 7

low = 0
high = len(data)-1

while low <= high:

    mid = (low + high) // 2

    if data[mid] == key:
        print("Data ditemukan")
        break

    elif data[mid] < key:
        low = mid + 1

    else:
        high = mid - 1

Hashing

Hashing adalah teknik penyimpanan dan pencarian data menggunakan hash function.

Contoh Program Hashing
hash_table = {}

hash_table[101] = "Andi"
hash_table[102] = "Budi"

print(hash_table)

if 101 in hash_table:
    print("Data ditemukan")
